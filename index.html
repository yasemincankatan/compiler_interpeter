Compiler und Interpreter

Quellcode übersetzen und ausführen

Teil 1 – Informationsquelle

Arbeitsauftrag:
Lesen Sie die folgenden Informationen aufmerksam durch. Bearbeiten Sie anschließend mithilfe der Informationen die Tabelle auf Ihrem Arbeitsblatt.

1. Grundidee

Programme werden von Menschen in einer Programmiersprache geschrieben. Der dabei entstehende Programmtext wird als Quellcode bezeichnet.

Ein Prozessor kann den Quellcode nicht unmittelbar als Maschinenbefehle ausführen. Der Quellcode muss deshalb in eine für die Ausführung geeignete Form übersetzt bzw. verarbeitet werden.

Dafür können unter anderem Compiler und Interpreter eingesetzt werden.

2. Compiler

Ein Compiler übersetzt den Quellcode eines Programms vor dessen Ausführung.

Quellcode → Compiler → ausführbarer Code → Ausführung

Der Compiler führt die Übersetzung durch, bevor das Programm ausgeführt wird. Das Ergebnis kann anschließend ausgeführt werden.

Wird der Quellcode verändert, muss die geänderte Version in der Regel erneut kompiliert werden.

Merksatz:
Der Compiler übersetzt den Quellcode vor der Ausführung.

3. Interpreter

Ein Interpreter verarbeitet Programmanweisungen während der Programmausführung.

Quellcode → Interpreter → Ausführung

Beim Interpreter sind die Verarbeitung des Programmcodes und dessen Ausführung eng miteinander verbunden.

Ein zuvor erzeugtes eigenständiges ausführbares Programm ist dabei nicht zwingend erforderlich.

Merksatz:
Der Interpreter verarbeitet den Programmcode während der Ausführung.

4. Der entscheidende Unterschied

Der wesentliche Unterschied zwischen Compiler und Interpreter liegt im Zeitpunkt der Verarbeitung des Programmcodes.

Compiler → Übersetzung vor der Ausführung

Interpreter → Verarbeitung während der Ausführung
Prüfungswissen:
Der Compiler übersetzt den Quellcode vor der Ausführung. Der Interpreter verarbeitet den Programmcode während der Ausführung.

6. Verständnis- und Anwendungsfragen

a) Ausführungsgeschwindigkeit

Warum kann ein kompiliertes Programm in der Regel schneller ausgeführt werden als ein Programm, bei dem der Quellcode während der Ausführung interpretiert wird?

Musterlösung:
Beim kompilierten Programm wurde der Quellcode bereits vor der Ausführung übersetzt. Während der Ausführung muss diese Übersetzung nicht erneut durchgeführt werden.

b) Python

Woran erkennt man, dass Python häufig als interpretierte Programmiersprache bezeichnet wird?

Musterlösung:
Python wird häufig als interpretierte Sprache bezeichnet, weil Python-Programme typischerweise über eine Laufzeitumgebung ausgeführt werden, die den Programmcode zur Laufzeit verarbeitet.

Hinweis: Die tatsächliche Verarbeitung von Python ist technisch komplexer als das vereinfachte Modell „Quellcode → Interpreter → Ausführung“.

c) Vorteil eines Interpreters

Welchen Vorteil kann ein Interpreter gegenüber einem Compiler haben?

Musterlösung:
Änderungen am Quellcode können ohne einen vorherigen separaten Übersetzungsschritt ausgeführt bzw. getestet werden.

d) Plattformabhängigkeit

Was bedeutet es, dass ein Programm plattformabhängig bzw. plattformunabhängig ist?

Musterlösung:
Ein plattformabhängiges Programm benötigt eine bestimmte Betriebssystem- oder Hardwareumgebung. Ein plattformunabhängiges Programm kann dagegen auf verschiedenen Systemen ausgeführt werden, sofern die erforderliche Laufzeitumgebung vorhanden ist.
